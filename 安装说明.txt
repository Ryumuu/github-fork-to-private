GitHub 一键复制到私有 — Chrome 扩展 1.1.3

安装（不需要编程，也不需要安装开发工具）
1. 将这个 ZIP 解压到一个长期保留的文件夹，例如“文档/Chrome扩展”。
2. 打开 Chrome，在地址栏输入 chrome://extensions 并回车。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后包含 manifest.json 的文件夹，不要选择 ZIP 文件。
6. 确认扩展显示版本 1.1.3。刷新 GitHub 页面，即可使用“复制到私有”。

提示
- 安装后不要删除或移动扩展文件夹。
- Chrome 需要以上手动加载步骤，双击 ZIP 不能自动安装。
- 可以点击 Chrome 工具栏的拼图按钮，将本扩展固定到工具栏。
- 需要 Chrome / Chromium 106 或更新版本。

更新
下载新版本，将解压后的文件更新到原先加载的扩展目录。
然后在 chrome://extensions 点击扩展卡片上的“重新加载”，核对版本并刷新 GitHub 页面。
如果自行修改过源码，请先备份再更新。手动安装不会自动更新。

使用与限制
登录 GitHub，打开要复制的公开仓库，点一次“复制到私有”即可。
自动填写地址、名称，选择 Private 并提交；同名自动加编号，不用填写 Token。
不用再点 Begin import；一键复制不受旧的手动确认设置影响。
自定义名称和本地复制在“更多选项”里；自动提交设置仅影响“手动链接”模式。
GitHub 可能需要几分钟完成导入；是否成功，以 GitHub 显示的结果为准。
当源仓库分支或历史 PR 记录很多时，GitHub 跳转后的 /import 进度页可能报 500 错误，但后台仍在继续复制；此时页面顶部会提示耐心等待并在后台导完后提示“已复制成功”，请勿重复点击。
GitHub 云端导入不包含 LFS 对象、Issues、PR 等平台数据。
“本地终端复制”是可选功能，只有使用它时才需要 Git 和已登录的 GitHub CLI。
完整说明见包内 README.md；安全说明见 SECURITY.md。
