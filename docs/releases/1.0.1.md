## 下载与安装

下载附件 **github-fork-to-private-1.0.1.zip**，这是已经打包好的 Chrome 扩展，使用时不需要 Git、Node.js 或 npm。

1. 解压 ZIP 到一个长期保留的文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的解压目录。
4. 确认版本为 **1.0.1**，刷新 GitHub 页面即可使用。

包内附有 `安装说明.txt`。请下载上面的扩展附件；GitHub 自动提供的 `Source code` 是开发源码压缩包。

Chrome 需要先解压、再手动加载目录，双击 ZIP 不能自动安装。安装后请保留目录；手动安装不会自动更新。已有安装可将新文件更新到原目录，再点击「重新加载」。需要 Chrome / Chromium 106 或更新版本。

## 1.0.1 的改进

- 提交导入前核对源地址、名称和 Private 状态，无法确认时停止。
- 拦截外部伪造的导入任务，多项任务分别处理，历史不再提前显示成功。
- 加固本地命令的输入处理和失败退出，复制全部 Git 分支、标签并保留默认分支。
- 补齐使用说明、安全说明和打包脚本；扩展运行文件无第三方依赖。

## 验证与限制

运行代码通过 54 项自动测试及 GitHub CI。测试包括临时本地 Git 仓库和浏览器表单检查；真实账号的云端导入结果、真实 LFS 对象迁移仍需在使用时确认。

这是代码复制工具，不是完整项目备份。GitHub 云端导入不迁移 LFS 对象、Issues、PR；本地脚本也不迁移 Releases 附件、项目设置等平台数据。详情见 [README](https://github.com/Ryumuu/github-fork-to-private/blob/main/README.md)。
