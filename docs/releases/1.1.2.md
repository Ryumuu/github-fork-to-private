# 1.1.2 — 修复翻译页面的自动导入 / Automatic import on translated pages

## 中文

- 修复翻译页面后反复提示“GitHub 尚未确认私有状态”的误报。现在核对 GitHub 回写的私有选项状态，不依赖固定英文句子，也不只看圆点是否选中。
- 名称可用检查兼容中文提示和文字包裹标签。更名前清除旧校验结果；默认名称被拒绝时有限尝试编号，自定义名称不会被擅自更改，未知错误仍停止。
- 点击“复制到私有”后，填写、选 Private、名称检查及 Begin import 均自动完成。旧的手动确认设置不会阻断一键入口。错误横幅显示运行版本。
- 88 项自动检查通过。实际加载扩展完成三次真实 GitHub 一键复制，包含模拟中文翻译、自动编号及延迟网络请求；三个结果均为独立私有仓库，匿名访问返回 404，分支与标签对象一致。详见 [验证记录](https://github.com/Ryumuu/github-fork-to-private/blob/main/docs/verification/1.1.2.json)。
- 不新增权限或依赖，不读取凭据。未逐一测试 Chrome 内置翻译及所有翻译插件；若翻译连仓库标识也改写，或 GitHub 无法确认状态，仍会停止。

更新后，在 chrome://extensions 重新加载并确认 **1.1.2**。关闭卡住的旧导入页，刷新源仓库页，再点一次“复制到私有”。旧页面不会自动获得新代码。测试浏览器已更新；常用 Chrome 的重新加载仍需用户操作。

## English

- Fixes false “GitHub has not confirmed private visibility” stops after page translation. Visibility checks now use GitHub-rendered option state, instead of a fixed English sentence or the selected radio alone.
- Name checks support Chinese status messages and wrapped text. Old validation is cleared before renaming. Rejected default names can advance through bounded numbered candidates; custom names are preserved, and unknown errors still stop submission.
- One click automatically fills the form, selects Private, checks the name, and submits Begin import. Older manual-confirmation settings do not block one-click actions. Error banners identify the running version.
- All 88 automated checks passed. Three real GitHub copies made with the installed extension completed, including simulated Chinese translation, automatic numbering, and delayed network requests. Each result was private and independent, returned 404 to anonymous access, and matched all branch/tag object IDs. See the [verification record](https://github.com/Ryumuu/github-fork-to-private/blob/main/docs/verification/1.1.2.json).
- No new permissions or dependencies; no credential access. Chrome's built-in translator and every translation extension were not individually tested. If translation changes repository identifiers, or GitHub cannot confirm the state, submission still stops.

Reload the extension at chrome://extensions and confirm **1.1.2**. Close stalled import pages, refresh the source repository page, and click Copy to private again. Old pages do not receive new code automatically. The test browser has been updated; reloading the separate everyday Chrome installation remains a user step.
