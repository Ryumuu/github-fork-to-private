# 1.1.1 — 自动完成最后提交 / Automatic final submission

## 中文

- 点击“一键复制”后，Private、地址和名称校验通过就立即提交，无需再点 GitHub 的 Begin import；旧的“关闭自动提交”设置不会阻断一键流程。该设置仍适用于“手动链接”模式。
- 修复 Private 圆点已选、但 GitHub 仍显示 Public 时的状态不同步。恢复期间禁止提交，最多尝试三次，必须确认真正的 Private 状态才继续。
- 保留任务、标签页、页面身份和提交前检查；不新增权限，不读取凭据。
- 自动化回归和真实浏览器验证见 [验证记录](https://github.com/Ryumuu/github-fork-to-private/blob/main/docs/verification/1.1.1.json)。

更新后请在 chrome://extensions 重新加载，确认版本为 1.1.1。关闭之前卡住的导入页，刷新源仓库页后重新点击“复制到私有”。旧导入页不会自动获得新代码或新任务。

## English

- One-click copying submits immediately after verifying Private, the source URL, and the target name. No further click on GitHub's Begin import is required. An older disabled auto-submit setting no longer blocks one-click actions; that setting still applies to Manual link mode.
- Recovers a checked Private radio when GitHub's application still says Public. Submission is blocked during recovery; at most three attempts are made, and verified Private state remains required.
- Task, tab, document, and pre-submit checks remain enforced. No new permissions or credential access.
- See the [verification record](https://github.com/Ryumuu/github-fork-to-private/blob/main/docs/verification/1.1.1.json) for automated and live browser checks.

Reload the extension at chrome://extensions and confirm version 1.1.1. Close the stalled import page, refresh the source repository page, and click Copy to private again. An old import page does not automatically receive new code or a new task.
